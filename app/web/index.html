O que é isto

Um sistema multiagente que conduz você por 5 percursos de lucro e 7 portas de decisão. Ele mede, diagnostica o vazamento, prioriza uma alavanca, delega handoffs aos agentes e cobra execução. Sem inventar número: o que falta aparece como [SEM DADO].

Comece pelo botão "Criar projeto demo" para ver o ciclo rodando com dados de exemplo, depois crie o seu.

Começar rápido

Gera um projeto completo com dados de exemplo e artefatos preenchidos (PRD, oferta, landing, preço, checklist).

Ordem recomendada

  1. Validar (G0): 15 conversas, 5 com gasto declarado.
  2. Sinal de dinheiro (G1): 3 pagos ou pré-pagos.
  3. Entregar (G2): 1 resultado medido antes/depois.
  4. Recorrência (G3): 3 mensalidades + 1 renovação.
  5. Canal (G4) e Margem (G5): 10 clientes/canal e custo de IA < 30%.

Nada avança sem evidência. É isso que impede você de construir no vazio.

Painel do negócio

O estado é a memória do sistema: o que você registra aqui é o que os agentes usam para decidir. Preencha números reais; deixe vazio o que ainda não mediu.

Ligar o LLM (opcional)

Sem chave, o sistema funciona 100% determinístico: calcula portas, unidade, gera artefatos e monta os handoffs. Com chave, os agentes também escrevem as peças (posts, propostas, planos) usando o Prompt Master + o estado real.

export BVC_LLM_API_KEY="sua-chave"        # compatível com OpenAI
export BVC_LLM_BASE_URL="https://api.openai.com/v1"   # qualquer endpoint compatível
export BVC_LLM_MODEL="gpt-4.1-mini"       # modelo mais barato que resolve
node app/server.mjs                        # reinicie o servidor

A chave fica só no servidor. O navegador nunca vê a chave — a SPA chama /api/… por URL relativa.

Rodar online

Este app é um servidor Node sem dependências. Para publicar: qualquer host que rode Node (Render, Railway, Fly.io, VPS) com node app/server.mjs e a variável PORT. Não há build, não há npm install.
