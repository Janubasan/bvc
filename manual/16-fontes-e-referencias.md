## 6. Como manter esta lista viva

```bash
# 1) Refazer a varredura do GitHub (trimestralmente)
curl -s "https://api.github.com/search/repositories?q=topic:affiliate-marketing&sort=stars&order=desc&per_page=25" \
  | jq -r '.items[] | "\(.stargazers_count)\t\(.full_name)\t\(.pushed_at[:10])"'

# 2) Novidades no Hugging Face
curl -s "https://huggingface.co/api/datasets?search=affiliate&limit=20&sort=lastModified" | jq '.[].id'
curl -s "https://huggingface.co/api/models?search=marketing&limit=20&sort=downloads"      | jq '.[].id'

# 3) Conferir política oficial dos programas que você usa (o que mais muda)
#    Amazon Associates Operating Agreement · termos Hotmart/Kiwify · Shopee Affiliate · TikTok Shop
```

Registre cada verificação em `templates/pesquisa-log.md` (data, fonte, o que mudou, ação tomada).
